1. Create a folder named `images/s1` in your repository (or your local working folder if you're not saving submission files to your repo). This is where you'll save **both** this template **and** every screenshot for this assignment.
2. Save this file into `images/s1/` and rename it: `lastname-S1_1-agile-docs.md`
3. Fill in your name, date, and repo URL above
4. Take each screenshot and save it directly into `images/s1/`, using the exact filename shown below each placeholder (e.g., `sprint_plan.md.png`)
5. Embed each screenshot in the placeholder below it — since the template and screenshots live in the same folder, the image links below already point to the right place and don't need to be edited
6. Export to PDF: right-click in VS Code → **Markdown PDF: Export (PDF)** — the PDF will save into `images/s1/` alongside the template and screenshots
7. Rename the PDF: `lastname-S1_1-agile-docs.pdf`
8. Submit to Blackboard → **S1_1 Agile Documentation**
